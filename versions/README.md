# Version history

Newest first. Every version keeps its own record file here. The latest version also has its tag and APK on the [Releases page](https://github.com/YashSomwanshi80/Game-Over/releases). Only the latest version is kept on the Releases page. On 2026-10-22 the releases and tags for v0.3.27, v0.3.28 and v0.3.29 were removed on purpose; their record files stay here as history. To add a version, follow [CONTRIBUTING.md](../CONTRIBUTING.md).
