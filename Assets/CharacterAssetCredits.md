# Character assets

Don: user-supplied Hi3D black-coat character export. Existing source terms retained.

Locomotion: user-supplied Idle, Walking, Running, Crouch_Idle and Crouch_Walking FBX files, in Mixamo format. Existing source terms retained.

Tapsee: adapted MakeHuman CC0 core assets: hm08 base, Asian/Caucasian female-young targets, young_caucasian_female2 skin, male_casualsuit01 overshirt, female_casualsuit01 jeans, shoes05 sneakers, ponytail01 hair, high-poly eyes and brown eye atlas. Custom optical frames, watch, crew-neck patch and native procedural skin micro-normal. Fitting, skinning and LOD conversion are project work.

Core asset authors include Data Collection AB, Joel Palmius and Jonas Hauquier, with original author credits retained in the authoring files. Licence information: https://static.makehumancommunity.org/about/license.html

Asset pack with individual licence listings: https://static.makehumancommunity.org/assets/assetpacks/makehuman_system_assets.html

Authoring sources and validation details are documented in outputs/RIGGED-CHARACTERS.md in the workspace.
