# Upper doorway finish

The existing DoorFrame generator now uses honed stone jambs/heads and a restrained timber rebate upstairs, including existing balcony doorway openings. It uses the same lintel position, opening width, floor and head height. Ground/basement doorway materials remain as before. The new meshes are decorative and add no collision.

FirstFloorLayout, BasementLayout and GameOver source hashes are unchanged by this pass. Runtime/editor C# compilation passed. This is a finish/legibility change, not a claim that all visible gaps have been verified in Unity. Check the bedroom, bathroom, suite and balcony openings in the existing scene after restarting Play.
